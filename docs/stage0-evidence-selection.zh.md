# Stage 0：完整目录与任务相关性粗筛

新默认流程为：**完整图谱目录 → 各来源统一三元组 → reranker 任务相关性粗筛 → Stage 2 候选事实计划**。
Stage 0 不再调用 LLM 根据有限代表样本硬删关系。旧 `refine_coarse` 与取样模板仅用于显式历史协议。

## 保存完整事实

- MKG-W 默认读取所选图划分的全部一跳邻居；图划分默认 `train`，不把测试集事实作为证据。
- 程序按关系、方向、邻居身份去重，完整原子事实保存在 `stage0_v3.facts`；元数据关系也保留。
- 新 Stage 1 根据完整目录构建三元组，不受旧 24 类关系、每关系 3 条或总计 32 条上限约束。
- 传给身份建模的图谱示例仍最多 32 条，同时给出关系计数。这限制模型输入，不限制程序的事实目录。
- 已有文本、图片观察、视频帧／片段和音频转写／声音观察分别接入，再统一保存主谓宾和来源引用。
- 二跳仍为每个一跳邻居最多 8 条的有界上下文，不能称为完整二跳子图。

事实 ID 保持稳定，方向保持原始主语和宾语。目标模态、ground truth、目标 description 和自邻居中的隐藏目标描述不作为输入。
Stage 0 的 `selection_method` 为 `catalogue_only`，关系状态为 `available`，不把未筛选记录伪装为模型选中或淘汰。

## Reranker 的职责

统一建模后，Qwen3-Reranker 比较生成任务与候选事实：

```text
Instruction：保留实体语义身份、定义性属性和重要关系，同时考虑目标模态表达；兼具两者价值的事实优先。
Query：目标实体 {entity_label}；目标模态 {target_modality}。
Document：(实体主语, 原始关系, 实体宾语)，保留关系方向。
```

query 不复制候选事实，document 不再提供包含同一事实的原证据包。这个分数衡量任务相关性，
不再解释为来源支持度、事实真实性或最终图像质量。文本生成、图像生成等任务使用不同目标模态。
Query 不再加入 Stage 1 模型归纳的实体类型，也不预设“图片只偏重颜色／形状”等固定偏好。
重要语义关系即使不能直接画出或听到，仍可保留；来源模态用于追溯，不进入相关性打分的 document。
指令版本为 `entity_semantics_modality_relevance_v2`，每个实体动态填入自己的标签，无固定博物馆模板。

每条事实都参与评分，本地按最多 8 对分批推理；按得分降序、事实 ID 稳定打破并列。
关系相关性取该关系下最高事实分，用于概览，不单独再调模型检查关系真假。
本地批处理与单条评分均使用包含 system/user/assistant 的完整 yes/no 模板；之前批处理漏掉的外层模板已补齐。

## 给 Stage 2 看多少

默认将相关性前 64 条送给 Stage 2，可通过 `--relevance-fact-budget` 或 Python API 的
`relevance_fact_budget` 调整。提示词、JSON Schema 和引用校验使用同一份事实 ID；
对应证据与身份依据一起传入，完整目录继续保存。

`relevance_selection` 记录 query、目标模态、完整数量、预算、入选 ID 和关系概览；
每条事实记录 `relevance_score`、`relevance_rank`。不使用固定分数阈值判定真假。
未入选意味着本轮未展示，不意味着事实被删除或已经证明无用；当前没有自动第二轮召回补查。

## 验证边界

离线回归覆盖 200 条事实、40 类关系均进入完整建模与 rerank，末尾事实可排到规划视图前列，
分批上限、来源引用、媒体时间位置、目标模态屏蔽、候选隔离及保存恢复。
这些检查证明数据边界和调用链，不证明高召回率。top-k 仍可能漏掉有用事实；
需要在标注关键事实的固定样本上测量召回与下游效果。

图片、视频、音频均通过两步感知接入：先生成描述，再结合描述与同一份原始媒体证据抽取事实。
视频由 ffmpeg 解码为带实际时间位置的画面（约每秒一帧）和完整主音轨；音频直接发送原文件。
保存完整原始文件指纹，明确区分完整文件与模型实际看到的采样画面。当前采样可能遗漏短暂事件，
不构成视频高召回保证。音轨与独立音频均需支持音频输入的模型，默认 Qwen2-VL 不具备此能力。
